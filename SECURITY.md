# Security policy

## Supported version

Security fixes are made on the current default branch. Older local builds are
not maintained.

## Reporting a vulnerability

Do not attach a ROM, save, voice pack, PC archive, or other copyrighted game
data to a public issue. Report the smallest synthetic reproducer possible and
include the application version, operating system, failing command, and whether
the input was retail or translated.

Sensitive reports use GitHub's **Security → Report a vulnerability** form.
Public issues must not contain exploit details or private game data.

The highest-priority reports are arbitrary file overwrite, path traversal,
memory-safety defects, corrupted output accepted as valid, forged restoration
receipts, and resource-pack integrity bypasses.
